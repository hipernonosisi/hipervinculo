# Architecture rules
- Standalone Supreme Herbals Shopify content has its own typed module shared by web, PDF and terms tests, preserving the older integrated proposal unchanged and reusing its document theme.
- BESAMIM uses a single typed English content and fee-calculation module shared by its web preview, PDF and financial tests; reuse the established proposal theme to preserve presentation and commercial consistency.
- Supreme Herbals uses one typed Spanish content module for the web proposal and PDF, with a document-scoped semantic theme matching the established proposal format, so commercial terms and presentation stay consistent.
- Industrial Advisors proposal content lives in one typed content module consumed by both the web proposal and the PDF renderer, so commercial terms stay consistent.
- Industrial Advisors uses the existing A4 document-preview pattern with expandable web pages and a matching React PDF layout, so the proposal remains consistent with the agency's other proposals without clipping long content.
- Client-shareable proposals use dedicated public, noindex routes and are also registered in the existing admin proposal menu, so clients need no admin access.
- Public bilingual pages share a route metadata registry and render to static HTML during Vite publishing, then hydrate the same router tree, so crawlers see route-specific content without changing the UI.
- Legacy redirects share one map for prerendering and browser navigation; emit a prerendered 404.html without canonical or JSON-LD, but do not claim Lovable's fixed index.html hosting fallback supports custom error documents or HTTP redirect rules.
- Maintain the existing static sitemap; lastmod is an explicit significant page revision date, never a build or generation timestamp.
- Content images use pre-sized WebP variants and a shared dimensions-aware image component to avoid excessive payloads and layout shifts.
- Incomplete leads and chat conversations reject direct client inserts/updates; server-side service-role writers preserve admin-only reads, preventing cross-visitor record tampering.
